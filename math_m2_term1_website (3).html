คณิตศาสตร์ ม.2 เทอม 1

สรุปเนื้อหาและแบบทดสอบตามแนวข้อสอบตัวอย่างที่ส่งมา

สารบัญ เลขยกกำลัง พีทาโกรัส ปริซึม ทรงกระบอก แบบทดสอบ

สารบัญ

1. สมบัติของเลขยกกำลัง

เน้นโจทย์จัดรูปหลายชั้น เลขชี้กำลังติดลบ และการทำให้อยู่ในรูปเลขชี้กำลังเป็นจำนวนเต็มบวก

2. ทฤษฎีบทพีทาโกรัส

เน้นโจทย์หลายสามเหลี่ยม การลากเส้นตั้งฉาก และการหาส่วนของด้าน เช่น ข้อ 4 และ 6

3. ปริซึม

เน้นปริมาตร พื้นที่ผิว และเส้นทแยงมุมในทรงสี่เหลี่ยมมุมฉาก

4. ทรงกระบอก

เน้นพื้นที่ผิว ปริมาตร ทรงกระบอกกลวง และโจทย์เปรียบเทียบกับปริซึม

5. แบบทดสอบ

โจทย์ประยุกต์หลายขั้น พร้อมตรวจคำตอบและวิธีทำ

1. สมบัติของเลขยกกำลัง

ส่วนนี้เน้นรูปแบบเดียวกับข้อ 1 ถึง 3 ในภาพตัวอย่าง

aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ เมื่อ a ≠ 0
(aᵐ)ⁿ = aᵐⁿ
(ab)ⁿ = aⁿbⁿ
a⁰ = 1 เมื่อ a ≠ 0
a⁻ⁿ = 1/aⁿ เมื่อ a ≠ 0
ตัวอย่างแนวข้อ 1:
((a⁻¹b⁴)/(b⁻¹c²))³ ÷ ((ab⁻³)/(b⁻²c³))⁻²
= (a⁻¹b⁵c⁻²)³ ÷ (ab⁻¹c⁻³)⁻²
= a⁻³b¹⁵c⁻⁶ ÷ a⁻²b²c⁶
= a⁻¹b¹³c⁻¹²
= b¹³/(ac¹²)
ตัวอย่างแนวข้อ 2:
((6x⁻²y)/(24xy²))⁻¹ ÷ ((4x⁴y)/(x⁻³y²))⁻³
= 4x³y ÷ (x⁻²¹y³/64)
= 256x²⁴/y²
ดังนั้น A = 256, B = 24, C = 2 และ A − B − C = 230
ตัวอย่างแนวข้อ 3:
(5¹⁵ − 5¹² + 248)/(5¹² + 2)
= [124(5¹²) + 248]/(5¹² + 2)
= 124(5¹² + 2)/(5¹² + 2)
= 124
เวลาจัดรูป ให้แยกฐานเดียวกันก่อน แล้วค่อยจัดการเลขชี้กำลัง

2. ทฤษฎีบทพีทาโกรัส

ใช้กับสามเหลี่ยมมุมฉาก โดยด้านตรงข้ามมุมฉากเป็นด้านยาวที่สุด

c² = a² + b²
ถ้าต้องการหาด้านประกอบมุมฉาก: a² = c² − b²
ตัวอย่างแนวข้อ 4:
AB = 7, AC = 5, BC = 8 และ AD ⟂ BC
ให้ DC = x จึงได้ BD = 8 − x
จากสามเหลี่ยม ADB: AD² = 7² − (8 − x)²
จากสามเหลี่ยม ADC: AD² = 5² − x²
เท่ากันได้ 49 − (8 − x)² = 25 − x²
แก้สมการได้ x = 2.5
ดังนั้น CD = 2.5 หน่วย
ตัวอย่างแนวข้อ 6:
สามเหลี่ยม ABE เป็นมุมฉาก โดย AB = 3 และ BE = 4
AE = √(3² + 4²) = 5
สามเหลี่ยม AED เป็นมุมฉาก โดย AD = 13
DE = √(13² − 5²) = 12
สามเหลี่ยม EDC เป็นมุมฉาก โดย DE = 12 และ DC = 16
EC = √(12² + 16²) = 20
ดังนั้น x = 20
โจทย์ลักษณะนี้ต้องดูเครื่องหมายมุมฉากทุกครั้ง แล้วเลือกใช้ด้านตรงข้ามมุมฉากเป็น c

3. ปริซึม

ปริซึมมีฐาน 2 ฐานที่เท่ากันและขนานกัน

ปริมาตร = พื้นที่ฐาน × ความสูง
พื้นที่ผิวข้าง = ความยาวรอบรูปของฐาน × ความสูง
พื้นที่ผิวทั้งหมด = พื้นที่ผิวข้าง + 2(พื้นที่ฐาน)
ตัวอย่างแนวข้อ 5:
ปริซึมสี่เหลี่ยมมุมฉากมี AB = 28 ซม. และ AF = 12 ซม.
กำหนดพื้นที่สามเหลี่ยม BDE = 210 ซม.²
เนื่องจาก DE = 12 ซม.
210 = 1/2 × BD × 12
จึงได้ BD = 35 ซม.
ในสามเหลี่ยม BDE มีมุมฉากที่ D
BE = √(35² + 12²) = 37 ซม.
เส้นรอบรูปสามเหลี่ยม BDE = 35 + 12 + 37 = 84 ซม.
พื้นที่มีหน่วยเป็นตารางหน่วย ส่วนปริมาตรมีหน่วยเป็นลูกบาศก์หน่วย

4. ทรงกระบอก

พื้นที่วงกลม = πr²
พื้นที่ผิวข้าง = 2πrh
พื้นที่ผิวทั้งหมด = 2πr² + 2πrh
ปริมาตร = πr²h
ตัวอย่างแนวข้อ 7:
ปริซึมมีความยาวรอบฐาน 44 นิ้ว และสูง 12 นิ้ว โดยฐานเป็นสี่เหลี่ยมจัตุรัส
ด้านของฐาน = 44 ÷ 4 = 11 นิ้ว
พื้นที่ฐาน = 11² = 121 ตารางนิ้ว
พื้นที่ผิวปริซึม = 44×12 + 2×121 = 770 ตารางนิ้ว
ทรงกระบอกมีเส้นรอบวงฐาน 44 นิ้ว และสูง 12 นิ้ว
2πr = 44 จึงได้ r = 7 นิ้ว เมื่อ π = 22/7
พื้นที่ผิวทรงกระบอก = 44×12 + 2×(22/7)×7² = 836 ตารางนิ้ว
พื้นที่ผิวต่างกัน = 836 − 770 = 66 ตารางนิ้ว
ตัวอย่างแนวข้อ 8:
ทรงกระบอกกลวงสูง 10 นิ้ว เส้นผ่านศูนย์กลางภายนอก 42 นิ้ว และเส้นผ่านศูนย์กลางภายใน 28 นิ้ว
รัศมีภายนอก = 21 นิ้ว และรัศมีภายใน = 14 นิ้ว
ปริมาตรเนื้อวัสดุ = πh(R² − r²)
= (22/7)×10×(21² − 14²)
= 7,700 ลูกบาศก์นิ้ว
ถ้าโจทย์ให้เส้นผ่านศูนย์กลาง ต้องหาร 2 เพื่อหารัศมี ก่อนแทนค่าในสูตร

แบบทดสอบแนวข้อสอบ

ชุดนี้เน้นรูปแบบโจทย์ใกล้กับภาพตัวอย่าง โดยเฉพาะโจทย์หลายขั้นและโจทย์ประยุกต์
